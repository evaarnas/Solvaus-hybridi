# Solvaus v0.2.15

- Competition mode offers **Shortest**, which waits for both engines and selects the shorter successful solution, and **Fastest**, which selects the first successful result and cancels the other engine.
- In Fastest mode, the cancelled engine's displayed progress and elapsed time stop at cancellation; the winning solution then replays.
- The Copy button is hidden for cubes above 21×21, where solution notation is unavailable.
- Draft releases include a debug-signed universal Android APK for sideloading.
